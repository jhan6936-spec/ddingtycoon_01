# 📢 띵타해 모드 v0.1.7 업데이트

v0.1.6에서도 **낚싯대로 어패류를 캐도 채집 횟수가 0**이던 문제를 수정했습니다.

## 증상
· 웹 연동·채집 목표 HUD는 정상 (굴 0/41, 문어 0/48 등 표시)
· `문어 (어패류)` 등을 낚싯대로 캐도 **횟수가 안 올라감**
· v0.1.6 JAR 적용해도 동일

## 원인
띵타해 어패류 채집은 **낚싯대 메커니즘**인데, v0.1.6은 엔티티 공격/우클릭만 감지해서 인벤에 들어온 어패류를 세지 못했습니다.

## 수정 내용 (v0.1.7)
· 인벤토리에 어패류가 들어오면 **채집 1회 = +1** (1~3성 여러 개여도 +1)
· **어부 룰렛 보너스** 추가 지급은 본 채집 직후에만 제외 (+0)
· 액션바에 룰렛 안내가 먼저 떠도 **본 채집은 정상 집계**

## 업데이트 방법
① https://ddingtycoon-01.vercel.app/#mod
② `ddingtae-fabric-0.1.7.jar` 또는 `ddingtae-forge-0.1.7.jar` 다운로드 (Ctrl+F5)
③ `.minecraft/mods`에서 **v0.1.6 이하 삭제** 후 교체
④ 게임 재실행

📋 패치노트 : 모드 페이지 **「패치노트」** 버튼

**지원** : Minecraft **1.21.4** · Fabric / Forge
(Fabric은 Architectury API **15.0.3** 필요)
