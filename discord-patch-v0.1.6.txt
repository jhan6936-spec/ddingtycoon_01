# 📢 띵타해 모드 v0.1.6 업데이트

v0.1.4~0.1.5에서 **채집 목표는 보이는데 횟수가 안 올라가던 문제**를 수정했습니다.

## 증상
· 웹 연동·스태미나 계산은 정상인데, 어패류를 캐도 채집 HUD가 **0에서 안 움직임**
· 어부 룰렛 각인 사용 시 핫바 위(액션바)에만 안내가 뜨는 경우가 많음

## 원인 (요약)
· v0.1.4에서 룰렛 **2중 카운트**를 막으려 인벤 감지를 끄면서, 실제 채집 인식까지 같이 막힘
· Forge에서 액션바(핫바 위) 메시지를 못 받는 경우도 있었음

## 수정 내용
· **직접 캔 어패류만** 채집 **1회 = +1** (1~3성 여러 개 들어와도 +1)
· **어부 룰렛 보너스** 추가 지급은 **+0** (본 채집과 분리)
· Forge **액션바** 메시지 인식 보강
· `처치`/`채집`이 있는 메시지는 룰렛 문구가 같이 있어도 본 채집으로 집계

## 업데이트 방법
① 웹 사이트 → **「띵타해 모드」**
② Fabric / Forge JAR 다운로드
   · `ddingtae-fabric-0.1.6.jar`
   · `ddingtae-forge-0.1.6.jar`
③ `.minecraft/mods`에서 **기존 v0.1.5 이하 삭제** 후 교체
④ 게임 재실행

🌐 **다운로드** : https://ddingtycoon-01.vercel.app/#mod
📋 **패치노트** : 모드 페이지 다운로드 옆 **「패치노트」**

**지원** : Minecraft **1.21.4** · Fabric / Forge
(Fabric은 Architectury API **15.0.3** 필요)

같은 증상이면 모드 버전·로더(Fabric/Forge) 알려주세요 🙏
