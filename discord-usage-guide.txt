**🌊 띵타해 — 띵타이쿤 해양 계산기 + 공식 보조 모드**

▸ **웹 계산기** : https://ddingtycoon-01.vercel.app
▸ **모드 다운로드** : 웹 사이트 왼쪽 메뉴 **「띵타해 모드」**
▸ **지원 버전** : Minecraft **1.21.4** · **Fabric / Forge** · 모드 **v0.1.13**

> 웹에서 연금·채집·재료를 계산하고, 모드로 게임 안에서 진행도·HUD·항해일지까지 이어서 볼 수 있어요.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🖥 【2】 웹 계산기 — 처음 쓰는 순서
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```
① 사이트 접속 → Discord로 로그인
② 「재료 창고」에 보유 재료 입력
③ 「개인설정」에서 해양 전문가 · 세이지 낚싯대 맞추기
④ 「효율 분석 → 연금품 계산」으로 추천 제작 확인
⑤ 필요하면 「스태미나 계산」으로 어패류 분배 확인
```

**자주 쓰는 메뉴**
• **재료 창고** — 모든 계산의 기준
• **연금품 계산** — 최적 제작 · 순이익 · 제작 시간
• **스태미나 계산** — 굴·소라·문어·성게·미역 분배 추천
• **제작 및 조합법** — 레시피 검색

💡 Discord 로그인 시 **이메일 인증**이 안 되어 있으면 로그인이 막힐 수 있어요.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📦 【3】 모드 설치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```
① Fabric Loader 또는 Forge 1.21.4 설치
② 웹 「띵타해 모드」에서 JAR 다운로드
   · Fabric용 / Forge용 중 본인 로더에 맞는 파일
③ .minecraft/mods 폴더에 넣기
④ 게임 실행
```

**게임 안에서 열기**
• 단축키 **`J`** → **띵타해 항해일지** (설정: 옵션 → 조작 → **띵타해**)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔗 【4】 웹 ↔ 마크 연동 (중요!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```
【게임】
① J 키 → 항해일지 → 「선원」 탭
② 오른쪽 아래 「웹 연동」 클릭
③ 채팅/화면에 뜨는 연동 코드 확인 (30분 유효)

【웹】
④ Discord로 로그인 (이미 했다면 생략)
⑤ 우측 프로필 → 「마크 연동」
⑥ 게임에서 받은 코드 입력 → 연동 완료
```

**연동되면**
• 웹 **스태미나·채집 목표** → 게임 HUD·항해일지에 반영
• 웹 **연금 계산·재료 창고** → 항해일지 **「목표」** 탭에 표시
• 게임 **어패류 채집** → 웹과 맞춰 **1회 +1**로 기록

**해제** : 게임 항해일지 「선원」→ **「로그아웃」** · 웹 프로필 → **「마크 연동 관리」→ 「연동 해제」**

> 게임에서만 해제했다면 웹에서도 **연동 해제**를 눌러 상태를 맞춘 뒤, 게임 **「웹 연동」**으로 새 코드를 발급해 다시 연결하세요.
> 코드 만료·실패 시 → 게임에서 **「웹 연동」** 다시 눌러 새 코드 발급


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎮 【5】 모드 주요 기능
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**제작 추적**
• 연금·공예·해양 제작 시 HUD에 **남은 시간·진행도** 표시

**어패류 채집 목표**
• 굴·소라·문어·성게·미역 채집 **횟수** 자동 기록
• **오전 3시** 기준으로 주기 초기화

**NPC 상점**
• 상점 열면 **매입·판매 가격** 자동 기록

**HUD · 알림**
• 채집 목표 · 제작 타이머 · **조개 출현** 알림
• **`J` → 개인설정 → HUD 위치** 에서 드래그로 배치 변경

**항해일지 탭**
• **목표** — 웹 연금·제작 목표
• **자원** — 수집·재료 현황
• **선원** — 웹 연동 · 개인설정

💡 【6】 추천 플레이 흐름
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```
1. 웹에서 재료·전문가 설정 → 연금/스태미나 계산
2. 모드 설치 후 웹 연동
3. 게임에서 채집·제작 → HUD로 진행 확인
4. 부족하면 웹 계산기 다시 열어 목표 수정
```
