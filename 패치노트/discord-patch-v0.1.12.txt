# 📢 띵타해 모드 v0.1.12 업데이트

**굴은 되는데 소라·문어·미역·성게가 안 올라가던** 문제를 수정했습니다.

## 원인 (v0.1.11)
· 채집 세션이 **낚싯바늘에 걸린 그 틱**에만 종을 기억
· 문어 등은 **즉시 채집**되어 바늘에 안 걸리면 세션 종이 비어 있음 → 인벤 +1 거절
· 굴은 미니게임·걸림 시간이 길어 우연히 맞았을 가능성

## 핵심 변경
```
낚싯바늘에 걸림 / 엔티티 상호작용
  → 대상 종 90초 기억 (바늘에서 떨어져도 유지)
  → 세션 + 기억 종과 맞는 인벤 증가 = +1
즉시 완료 채집
  → 낚싯대 시전 후 20초 안 인벤 증가도 보조 인정
  → 알쏭달쏭 조개·재활용품 등은 여전히 제외
```

· 인벤 감지: 슬롯별 **실제 아이템 이름** 사용 (성급 섞임 오인 방지)
· ★☆✦⭐ 성급 표기 인식 보강
