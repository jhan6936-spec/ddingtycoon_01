# 📢 띵타해 모드 v0.1.11 업데이트

채집 횟수가 **안 올라가거나**, 반대로 **엉뚱한 아이템까지 세지던** 문제를 한꺼번에 수정했습니다.

## 증상
· 일반 채집(미니게임 없이 바로 완료) — 채팅 신호 없어서 HUD 0
· 해양 미니게임 / 재연동 후에도 0인 경우 (v0.1.10)
· 알쏭달쏭 조개·가오리 인도 재활용품이 채집으로 잡히던 경우 (v0.1.7~0.1.10 유예 구간)

## 핵심 변경 — 「채집 세션」
```
낚싯바늘에 어패류 걸림 / 엔티티 상호작용
  → 채집 세션 오픈 (90초, 종 기억)
  → 그동안 해당 종 인벤 증가 = +1
  → 세션 없으면 인벤만으로는 절대 +1 안 함
```

· **일반 채집** : 완료 채팅 없어도 낚싯대→인벤 경로로 집계
· **미니게임** : 성공 시 세션 종으로 +1, 인벤 중복은 제외
· **과다 집계 방지** : 재연동 유예 무조건 +1 제거, 5종+제외 목록만

## 업데이트 방법
① https://ddingtycoon-01.vercel.app/#mod
