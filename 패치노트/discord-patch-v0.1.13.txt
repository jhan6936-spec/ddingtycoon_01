# 📢 띵타해 모드 v0.1.13 업데이트

**뭘 캐도 굴로만 올라가던** 문제 수정 + **항해일지 연출** + **업데이트 알림** 추가입니다.

## 버그 수정 — 어패류 집계
· v0.1.12에서 인벤 비교가 **Item 종류 단위**라, 핫바에 굴이 있으면 문어·성게도 굴 +1 되던 문제
· **슬롯별** 개수·이름으로 비교하도록 변경
· 해양 미니게임 성공 시 세션 종(굴)으로 바로 +1 하던 경로 제거 → **실제 획득 아이템** 기준

## 신규 — 항해일지 열기 연출
· **J** 키로 항해일지를 열 때 아래에서 살짝 올라오며 페이드인 (약 0.26초)

## 신규 — 업데이트 알림
· 마인크래프트 **메인 메뉴** 진입 시 사이트 최신 버전 확인
· 새 버전이 있으면 알림 + **[예] [아니요]**
  · **예** → 모드 다운로드 페이지 열기
  · **아니요** → 메인 메뉴 그대로 (해당 버전은 다시 안 뜸)

## 업데이트 방법
① https://ddingtycoon-01.vercel.app/#mod
② `ddingtae-fabric-0.1.13.jar` 또는 `ddingtae-forge-0.1.13.jar` (Ctrl+F5)
③ `.minecraft/mods`에서 **구버전 JAR 삭제** 후 교체
④ **게임 완전 종료 후 재실행**
