# 📢 띵타해 모드 v0.1.18 업데이트

**웹 사이트 일시 중지(Vercel 무료 한도 초과) 예방**을 위해 웹↔모드 API 호출 간격을 대폭 줄였습니다.

## 배경
· 6월 중순부터 웹 연동 유저가 늘면서 Vercel Edge Requests가 **100만 한도의 3배**까지 증가
· 사이트가 `402 DEPLOYMENT_DISABLED`로 접속 불가 상태가 됨
· 원인: 모드·웹이 `/api/minecraft/dashboard` 등을 **초 단위로 반복 호출**

## 변경 (모드)
· 대시보드 동기화: **1초 → 30초**
· 연동 코드 확인(웹 입력 대기): **0.5초 → 2초**
· 미연동 세션 복구: **3초 → 60초**

## 변경 (웹)
· 계산기 조작 시 대시보드 전송: **최소 30초 간격** (연속 변경은 묶어서 1회 전송)
· 구버전 모드는 여전히 1초마다 폴링하므로 **모드도 함께 업데이트** 권장

## 참고
· 웹에서 바꾼 목표가 게임 HUD에 반영되기까지 **최대 약 30~60초** 걸릴 수 있음
· 서버 부하가 크게 줄어 사이트 중단 위험이 낮아짐

## 업데이트 방법
① https://ddingtycoon-01.vercel.app/#mod
② `ddingtae-fabric-0.1.18.jar` 또는 `ddingtae-forge-0.1.18.jar` (Ctrl+F5)
③ `.minecraft/mods`에서 **구버전 JAR 삭제** 후 교체
④ **게임 완전 종료 후 재실행**
⑤ 웹도 새로고침(Ctrl+F5) 후 재접속
