# 📢 띵타해 모드 v0.1.8 업데이트

v0.1.7에서 **인벤에 들어오는 것이 전부 어패류 채집으로 잡히던** 문제를 수정했습니다.

## 증상 (v0.1.7)
· **알쏭달쏭 조개**가 어패류 채집 횟수에 포함됨
· **가오리 인도**로 주워지는 **재활용품**도 채집으로 카운트됨
· 인벤에 들어오는 아이템이 거의 다 집계되는 느낌

## 원인
v0.1.7은 낚싯대 채집을 살리려고 인벤 증가를 넓게 잡았는데, 어패류 이름 판별이 느슨해서 조개·재활용품 등도 굴 등으로 인식됐습니다.

## 수정 내용 (v0.1.8)
· **굴·소라·문어·미역·성게 5종**만 채집으로 인정
· **알쏭달쏭 조개·재활용품** 등은 제외
· **낚싯대 사용/캐스팅** 또는 **어패류 엔티티 상호작용 직후** 인벤에 들어온 경우만 +1
· 채집 1회 = +1, 어부 룰렛 보너스 추가 지급은 제외 (v0.1.7과 동일)

## 업데이트 방법
① https://ddingtycoon-01.vercel.app/#mod
② `ddingtae-fabric-0.1.8.jar` 또는 `ddingtae-forge-0.1.8.jar` 다운로드 (Ctrl+F5)
③ `.minecraft/mods`에서 **v0.1.7 이하 삭제** 후 교체
④ 게임 재실행

📋 패치노트 : 모드 페이지 **「패치노트」** 버튼

**지원** : Minecraft **1.21.4** · Fabric / Forge
(Fabric은 Architectury API **15.0.3** 필요)
